# Plataforma de Monitoreo Ambiental Urbano

**Integrantes del Grupo:**
- Sofia Piza

## Descripción del Proyecto
Núcleo de procesamiento, validación y almacenamiento dinámico de datos para la Red de Monitoreo Ambiental. Desarrollado en Java puro, aplicando estructuras de datos modulares (TAD), control de excepciones, matrices bidimensionales y algoritmos de búsqueda lineal y binaria.

## Ejecución
1. Asegurar que `lecturas_ampliadas.csv` esté en la carpeta `data/`.
2. Compilar: `javac src/*.java`
3. Ejecutar: `java -cp src IngestaSensores`
